# ShipWheel

Put a **Ship Wheel** on a boat or car build, right-click it, and drive the build.

This repo has the Paper plugin (Java). Related files are in the same repo under `extras/`.

## Paper plugin (ShipWheel 2.0.0)

- Needs **Paper 26.3** and **Java 25+**.
- Get a wheel: `/shipwheel give [player]` (op) or craft 8 sticks around dark oak planks.
- Place the wheel on a build, right-click it. The connected build (not natural terrain, not chests or furnaces) turns into display entities carried by an invisible horse. You ride it like a horse. No jumping.
- Sneak to get off. The build turns back into solid blocks at the new spot, snapped to the block grid and the nearest 90 degree turn. If there is no room, you stay on.
- A backup of the blocks is saved while you ride, and restored on server start after a crash.
- `/shipwheel showcase` builds a small demo (islands, a road, boats, cars).

Limits: the build has no collision of its own while moving (only the horse collides), big builds cost client FPS, and lag can make the visuals trail the horse.

Build it yourself: `mvn package` (Java 25).

## Honest status

- Tested on a real Paper 26.3 server from the console: build to entities, move, back to blocks, same block count. Not yet tested by a person riding it. Feel and smoothness are unverified.
- Parts of this project, including most of the code, were written with the help of generative AI, then compiled and tested. Textures are generated by script.
